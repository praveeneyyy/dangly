# Dangly v1.0.0 — Release Notes & Downloads

A tactile ornament hangs from your screen on a 240 Hz simulated rope. Nudge it and it swings, carries momentum, and settles — because it is real physics, not a canned looping animation.

This release brings full dual-platform support for **Windows** and **macOS**, dynamic cord stretching with elastic snap-back recoil, a redesigned minimalist dark settings interface, and the official Dangly icon and branding.

## 🚀 Installation & Getting Started

### Windows (Windows 10 / 11)

1. **Download**: Grab [`dist/Dangly-Windows.zip`](../../dist/Dangly-Windows.zip) or use the pre-built [`dist/windows/Dangly.exe`](../../dist/windows/Dangly.exe).
2. **Extract**: If using the zip, extract all files into a folder of your choice.
3. **Run**: Double-click `Dangly.exe`.
4. **Controls**:
   - The charm appears anchored near the top right of your display.
   - Click and drag to swing or fling the charm across your desktop.
   - Drag downward toward the bottom of the screen to stretch the cord, then release to watch it snap back with dynamic swinging recoil.
   - Right-click the system tray icon or double-click the charm to open the **Settings** window.

> [!NOTE]
> If Windows SmartScreen displays *"Windows protected your PC"* on first launch, click **More info** $\rightarrow$ **Run anyway**.

---

### macOS (macOS 14 Sonoma or later, Apple Silicon)

#### Option 1: 1-Click Build from Package (Offline / Local)
1. **Download**: Grab [`dist/Dangly-macOS.zip`](../../dist/Dangly-macOS.zip) and unzip it on your Mac.
2. **Double-Click**: Open the folder and double-click `Build-On-Mac.command`.
3. **Run**: The script compiles `Dangly.app` (and optional `Dangly.dmg`), then reveals it in Finder. Drag `Dangly.app` to your `/Applications` folder and launch.

#### Option 2: Open in Xcode
1. Unzip `Dangly-macOS.zip`.
2. Double-click `macos/Hangly.xcodeproj` to open it in Xcode.
3. Press **Cmd + R** to run immediately, or select **Product $\rightarrow$ Archive** to export a signed `.app`.

#### Option 3: Download from GitHub Actions
1. Navigate to the repository's [GitHub Actions](https://github.com/praveeneyyy/Dangly/actions) tab.
2. Select the latest build run.
3. Download the `Dangly-macOS-app` artifact for a pre-compiled native Apple Silicon app.

> [!IMPORTANT]
> **First launch Gatekeeper prompt**: If macOS displays *"Dangly cannot be opened because the developer cannot be verified"*, right-click `Dangly.app`, select **Open**, and confirm **Open** once.

## ✨ What's New in v1.0.0

### 🪢 240 Hz Verlet Rope Dynamics & Elastic Recoil
- **Dynamic Stretch**: The cord can now be dragged continuously down to the bottom of the screen. Segments expand proportionally as distance grows.
- **Elastic Recoil**: Releasing the stretched cord unleashes stored elastic strain energy, accelerating the charm upward and converting potential energy into swinging oscillations ("moving and moving").
- **Fixed Timestep**: Evaluated at 240 Hz ($dt = 1/240\text{ s}$), ensuring rock-solid physics stability across 60 Hz, 120 Hz, and variable refresh rate displays.
- **Simulated Beads**: Independent particles riding the cord curve with resting offset tethering and non-penetration separation.

### 🧿 16 Hand-Crafted Charms
- **11 Cultural Charms**: Nazar Boncuğu, Hamsa, Drishti Bommai, Daruma, Maneki-neko, Ghanta, Scarab, Pánchang Jié, Nimbu-mirchi, Horseshoe, and Himmeli.
- **5 Geometric Classics**: Circle, Star, Heart, Diamond, and Camera.
- **Physical Personalities**: Each charm features tuned mass, size, acoustic resonance, and auto-tinted cord palettes.

### 🎨 Minimalist Dark Settings Window
- Ultra-clean dark theme (`#0F0F11` background, `#18181B` surface cards, `#27272A` borders, `#3B82F6` accent).
- Borderless segmented navigation tabs for quick switching between Charms, Dynamics, Display, Sound, and General settings.
- Smooth hover feedback and card-grouped controls.

### 🖼️ Charm Studio & Custom Image Uploads
- Drag and drop any `.png`, `.jpg`, `.jpeg`, `.webp`, or `.bmp` file onto the charm or studio.
- Smart luminance background cutout and flood-fill isolation with real-time tolerance sliders.
- Customizable knot inset and mass scaling.

### 🔔 Physical Audio Synthesizer
- On-device harmonic additive synthesizer at 44.1 kHz producing Wood, Bell, Glass, Metal, and Soft impact acoustics.
- Support for custom `.wav` sounds in Charm Studio.
